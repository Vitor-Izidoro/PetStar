# 🐾 PetStar

**PetStar** é um site com o objetivo de ajudar pessoas que precisam de alguém para cuidar de seu cachorro enquanto estão fora.  
A ideia é conectar donos de pets a cuidadores de forma simples, rápida e segura.

---

## 🚀 Funcionalidades

- 📋 Cadastro de usuários (donos e cuidadores).  
- 🐶 Cadastro de pets com informações básicas (nome, idade, raça, observações).  
- 🔎 Busca de cuidadores disponíveis na região.  
- 💬 Possibilidade de contato entre dono e cuidador.  
- ⭐ Avaliações para garantir confiança e segurança.  

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** [React](https://reactjs.org/)  
- **Backend:** [Node.js](https://nodejs.org/) + [Express](https://expressjs.com/)  
- **Banco de Dados:** [MySQL](https://www.mysql.com/)  
- **Outros:** HTML5, CSS3, JavaScript
